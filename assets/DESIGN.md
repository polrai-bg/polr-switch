# Loftlane icon

Original project artwork generated with the built-in OpenAI image-generation tool. No reference logo was supplied. `Loftlane.png` is the full-resolution master with transparency; `build.sh` creates the macOS ICNS family from it.

## Prompt

Use case: logo-brand. Create one finished macOS application icon for an original independent app named Loftlane, a calm elegant utility for keeping multiple workspaces organized. Icon only, no text or letters. A dark midnight navy rounded square tile, with three sculptural softly glowing arched doorway panels arranged as parallel offset lanes: nearest in icy mint and teal, middle luminous periwinkle blue, rear muted warm apricot. The panels are distinct open doorways, not solid pills. Architectural, dimensional, sophisticated Apple desktop utility aesthetic. Strong simple memorable silhouette at 32 pixels. Subtle frosted glass depth and beautiful restrained rim highlights, no visual clutter, no tiny details, no stars, no Claude or Anthropic starburst, no existing logos, no mascots, no mockup context. Straight-on centered composition. Entire icon fits comfortably in a square canvas with a small transparent outer margin. The rounded navy tile and artwork are opaque, outside tile is actually transparent. Output a single crisp square icon, not a grid or alternatives.
